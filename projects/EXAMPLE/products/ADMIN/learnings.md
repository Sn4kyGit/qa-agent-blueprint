# Learnings — SHOP/ADMIN (FICTIONAL EXAMPLE)

Product-scoped learnings. `../../learnings.md` (project-wide) still applies — read
both, they are never merged into one view. Format: newest on top; dated; 1–3
sentences; Problem → Cause → Solution; bump `seen:` on recurrence and note which
product each sighting came from; delete what no longer holds.

Deliberately empty: a freshly onboarded product has no learnings yet, and inventing
some would be exactly the kind of plausible-looking fiction the blueprint forbids.
The first surprise during the first real test run goes into
`memory/learnings/_inbox.md` and lands here at the next `/retro-learn` pass.
